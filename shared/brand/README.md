# BiasharaOS business doodle

`biashara-doodle.png` is the original transparent emerald wallpaper, with shops, produce, deliveries, a matatu, events, services and recurring two-leaf growth marks. Keep the original PNG as the source asset. Android uses an identical drawable copy; the website uses a smaller lossless WebP encoding of the same art.

Use it sparingly on welcome/landing surfaces, brand callouts and the assistant conversation background. Keep tables, financial forms and operational records plain. Content, buttons and chat bubbles remain opaque and readable above the pattern. Treat it as decorative: no accessibility announcement, interaction or animation.

Web uses 560–640px tiles at low opacity. Android repeats the same art with a theme tint. Preserve the pattern's proportions, transparent background and visual spacing when adding another use.

The reusable original is also served at `/brand/biashara-doodle-v1.png` for downloading and future brand work.
