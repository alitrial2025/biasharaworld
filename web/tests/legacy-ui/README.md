# Retired local-demo browser specifications

These specifications describe the pre-backend prototype: invented sign-in, shared browser-local sample data, simulated sync and public numeric customer links. They are retained as UI history, not active acceptance criteria. The live backend intentionally removes those behaviors. `e2e/live-workspace.spec.ts`, the existing domain contracts and `tests/live-backend.mjs` verify the replacement against real isolated Supabase accounts. Do not report these retired specifications as passing.
